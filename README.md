# 우리팀 허브

팀 소통·공지를 한 화면에서 보는 웹앱입니다. 휴대폰·PC 어디서든 열 수 있고, 홈 화면에 추가하면 앱처럼 쓸 수 있습니다.

- **바로 열기:** https://leanonmept.github.io/team-hub/
- **만든 방식:** 단일 HTML 파일(`index.html`) — 별도 빌드 없이 GitHub Pages로 서빙됩니다.

## 화면

- **공지** — 공지 작성·고정·중요 표시, 댓글, 읽음 확인
- **당직** — 🛡️ 당직 달력과 ⛴️ 섬·교육 달력을 탭으로 분리
  - 🛡️ 당직: 월~금 5열 달력(큰 이름 배지) · 공휴일 자동 연동(빨간 날짜 + 공휴일명) · 당직 명단(가나다순, 제외/포함, 회원이 아닌 사람 직접 추가·수정·삭제) · 매월 24일 0시 이후 첫 접속 때 다음 달 자동 배정 · 재배정(비교 후 적용) · 행사일(등록하면 그날 당직 취소 + 달력 칸 전체 연보라 음영에 행사명 표시) · 팀원끼리 담당자 변경(한 날짜 1명, 바꾸면 기존 담당자 교체 + 변경 이력) · 칸 맨 위 당직자 아래에 등판(빨강)·의소기한(파랑)·조사기한(초록) 자동 표시(등판 2026-12-09부터 격주 수요일, 의소기한 전주 목요일, 조사기한 하루 전 · 관리자·당직 관리 권한자는 날짜 상세에서 붙이거나 뺄 수 있음)
  - ⛴️ 섬·교육: 일~토 7열 달력에 당일 섬 · 1박 섬 · 교육 일정. 여러 날 일정(1박 섬·연속 교육)은 주 안에서 가로 막대로 이어서 표시
- **사진** — 팀 사진 공유
- **대화** — 팀 단체방
- **팀원·설정** — 팀원 승인, 직책(주임·대리·과장·팀장·센터장·부장) 변경, 관리자/당직 관리 권한 부여·해제

## 처음 설정하기

처음에는 **미리보기 모드**(내 기기에만 저장)로 열립니다. 실제로 팀과 함께 쓰려면 Firebase를 연결하세요.

1. Firebase 콘솔에서 새 프로젝트를 만들고, Authentication에서 **이메일/비밀번호** 로그인을 켭니다. (앱은 로그인에 쓰는 사번을 `사번@teamhub.local` 가상 이메일로 바꿔서 씁니다 — 사용자에게는 이메일이 보이지 않습니다.)
2. Authentication → Settings → **승인된 도메인**에 `leanonmept.github.io`를 추가합니다.
3. Firestore Database를 만듭니다(위치: `asia-northeast3` 서울 권장).
4. 이 저장소의 [`firebase-rules.txt`](firebase-rules.txt) 내용을 Firestore 규칙 탭에 붙여넣고 게시합니다.
5. 앱의 설정 화면에서 Firebase 웹 앱 설정값(`apiKey`, `authDomain`, `projectId`, `appId` 등)을 입력합니다.
6. 첫 관리자 지정 방법은 `firebase-rules.txt` 맨 위 주석을 참고하세요.

## 참고

- `firebase-rules.txt`는 Firebase 콘솔에 붙여넣는 보안 규칙 원본입니다(웹 화면에서는 쓰이지 않습니다).
- 저장소를 고쳐도 Pages 반영까지 1분 안팎 걸릴 수 있습니다.
- 당직 자동 배정은 평일(주말·공휴일·행사일 제외)만 대상으로 하며, 12월은 명단 처음부터, 1월 이후는 전달 마지막 당직자 다음 사람부터 이어집니다.
- 앱 권한은 **관리자**(승인·권한 부여)와 **당직 관리**(명단·재배정·행사일·자동 배정)로 나뉘고, 직책(position)과는 별개입니다.
- 공휴일은 내장 표(2026~2028, 한국천문연구원 월력요항 기준)와 연도별 온라인 자료(`date.nager.at`)를 합쳐 씁니다. 한 번 받은 연도는 브라우저에 캐싱되고, 내장 표가 있는 날짜는 내장 표를 우선합니다.
